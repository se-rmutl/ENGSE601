# สัปดาห์ที่ 17 — สอบปลายภาค

**หน่วย/บทเรียน:** การประเมิน CLO3–CLO6  
**กิจกรรมหลัก:** Final Assessment  
**ชิ้นงานหลัก:** ผลการประเมินและแผนพัฒนาต่อเนื่อง

## เป้าหมายของสัปดาห์

ประเมินการวางแผน การควบคุม การวิเคราะห์ผล และการใช้หลักฐาน V&V

## สิ่งที่ต้องเตรียม

- เอกสาร/ชิ้นงานจาก repository ENGSE212 ของกลุ่มที่เกี่ยวข้องกับหัวข้อสัปดาห์นี้
- อ่านสื่อใน [resources.md](resources.md) เมื่อผู้สอนเผยแพร่แล้ว
- เตรียมคำถามหรือความเสี่ยงที่พบจากโครงงานจริง

## ขั้นตอนการทำกิจกรรม

1. ทบทวนแนวคิดและตัวอย่างจากผู้สอน
2. ใช้บริบทของโครงงานหรือกรณีศึกษาเพื่อทำกิจกรรม
3. แลกเปลี่ยนกับเพื่อนผ่าน pair/team/peer review ตามรูปแบบที่ผู้สอนกำหนด
4. ปรับปรุงชิ้นงานตาม feedback
5. commit และส่งหลักฐานใน repository ของกลุ่ม
6. บันทึก AI Use Declaration หากใช้ AI ช่วยงาน

## สิ่งที่ต้องส่ง

- **ผลการประเมินและแผนพัฒนาต่อเนื่อง**
- หลักฐานประกอบที่ตรวจสอบย้อนกลับได้
- ลิงก์หรือ path ไปยัง requirement / design / code / test result ที่เกี่ยวข้อง

## เกณฑ์คุณภาพขั้นต่ำ

- สอดคล้องกับ requirement และบริบทระบบ
- มีเหตุผลในการเลือกเทคนิคหรือกลยุทธ์
- ตรวจสอบย้อนกลับได้จาก requirement → test → evidence
- สื่อสารชัดเจนและใช้ AI อย่างโปร่งใส
