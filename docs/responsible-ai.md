# Responsible AI in Software V&V

## AI ช่วยอะไรได้

- ช่วยตั้งคำถามต่อ requirement ที่กำกวม
- ช่วยเสนอ acceptance criteria และ test conditions
- ช่วยเสนอกรณีทดสอบ / test data ในระดับ “ร่าง”
- ช่วยตรวจรูปแบบและความชัดเจนของรายงาน
- ช่วยสรุปประเด็นจาก defect log หรือ review record

## นักศึกษาต้องทำอะไรเสมอ

1. ตรวจสอบผลลัพธ์กับ requirement, design, source code และผลทดสอบจริง
2. อธิบายเหตุผลก่อนนำคำตอบของ AI ไปใช้ในชิ้นงาน
3. ระบุ prompt โดยสรุป ผลที่นำมาใช้ และวิธีตรวจสอบ
4. ปกป้องข้อมูลของโครงงานและข้อมูลส่วนบุคคล

## สิ่งที่ห้าม

- สร้าง test result, screenshot, defect หรือหลักฐานใดที่ไม่ได้ดำเนินการจริง
- ส่งข้อความจาก AI โดยไม่ตรวจความถูกต้อง
- ใส่ข้อมูลลับ, credentials, source code ที่ไม่ได้รับอนุญาต หรือข้อมูลส่วนบุคคลลงใน AI
- ปิดบังการใช้ AI เมื่อ AI มีส่วนช่วยงานที่ส่ง
