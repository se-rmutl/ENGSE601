### วิธีส่งงานกลุ่ม

1. วางไฟล์ตามตาราง แล้ว commit และ push
2. กรอกตาราง “งานที่ต้องส่ง” ใน `SUBMISSIONS.md` ให้ครบ
3. ผู้ส่งหลักสร้าง Release ชื่อ **`engse601-submit`** (Releases → Draft a new release → tag `engse601-submit` → Publish)
4. ผู้ส่งหลักกรอกลิงก์ repo ใน Google Form (ข้อ 1)

แก้หลังสร้าง Release ได้ก่อนปิดรับ โดยสร้าง Release ใหม่ `engse601-submit-v2` · ผู้สอนตรวจ Release ล่าสุดที่สร้างก่อนปิดรับ

## 3. กติกา (อ่านก่อนส่ง)

1. **repo เป็น Public** → ห้ามใส่รหัสนักศึกษา ในไฟล์ ชื่อไฟล์ หรือ `SUBMISSIONS.md` · ใช้ชื่อและ GitHub username ใน `TEAM.md`
2. **ห้ามวางงานเดี่ยวส่วน A** ใน repo · ใบงานครั้งที่ 1 ให้แยกเฉพาะส่วน B ไปวาง
3. ตารางในใบงานที่มีช่องรหัสนักศึกษา ให้เว้นว่างเมื่อวางใน repo
4. **ผลทดสอบต้องมาจากการรันจริง** · รันไม่ได้ให้เขียน `Not Executed` พร้อมเหตุผล ได้คะแนนตามเกณฑ์ · แต่งผลหรือหลักฐาน ส่วนนั้นได้ 0
5. ทีมที่ยังไม่มีข้อมูลโครงงานพอ ทำเท่าที่มีจริง แล้วเขียนช่องว่างให้ชัด · ห้ามสร้างเอกสารหรือผลย้อนหลังเพื่อให้มีของส่ง
6. คะแนนกลุ่มเท่ากันทุกคน ผู้สอนปรับรายคนได้จาก `TEAM.md` จึงต้องบอกให้ชัดว่าใครทำส่วนไหน
