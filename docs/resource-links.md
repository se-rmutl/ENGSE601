# ศูนย์รวมลิงก์สื่อการสอน

ผู้สอนสามารถเพิ่ม URL ของ PowerPoint, PDF, Canva, วิดีโอ, เอกสารอ้างอิง หรือแบบส่งงานลงในไฟล์ `resources.md` ของแต่ละสัปดาห์ได้

รูปแบบแนะนำ:

```md
- Slides: [PowerPoint](https://example.com)
- Reading: [PDF](https://example.com)
- Activity board: [Canva / Miro](https://example.com)
- Submission: [LMS / Google Classroom](https://example.com)
```

> หลีกเลี่ยงการใส่ข้อมูลส่วนตัวของนักศึกษาในลิงก์สาธารณะ
