# คู่มือรายวิชา ENGSE601

## แนวคิดหลัก

รายวิชานี้สอนให้มองซอฟต์แวร์ไม่ใช่เพียง “รันได้” แต่ต้องมีหลักฐานว่า **ถูกต้องตามข้อกำหนด**, **ตอบโจทย์ผู้ใช้** และ **มีคุณภาพเพียงพอสำหรับบริบทการใช้งาน**

## รูปแบบการเรียนรู้

- เรียนแนวคิดผ่านกรณีศึกษาและการอภิปราย
- ทำกิจกรรมสั้นในชั่วโมงเรียน โดยไม่เพิ่มชั่วโมงปฏิบัติในโครงสร้างรายวิชา
- ใช้เอกสารหรือระบบของ ENGSE212 เป็นบริบทเมื่อเหมาะสม
- สร้าง V&V Evidence Portfolio ต่อเนื่องตลอดภาคเรียน
- ทบทวนงานแบบ peer review และบันทึกการตัดสินใจ

## วิธีเตรียมตัวในแต่ละสัปดาห์

1. อ่าน README ในโฟลเดอร์สัปดาห์
2. เปิดลิงก์สื่อใน `resources.md` เมื่อผู้สอนเพิ่มลิงก์แล้ว
3. เตรียมเอกสาร/โค้ด/ต้นแบบจากโครงงานที่เกี่ยวข้อง
4. ทำกิจกรรมตามขั้นตอนและส่งชิ้นงานใน repository ของกลุ่ม
5. ระบุการใช้ AI และวิธีตรวจสอบผลทุกครั้งที่ AI มีส่วนร่วม

## กติกาการส่งงาน

- ใช้ Markdown หรือไฟล์ตาม template ที่ผู้สอนกำหนด
- ตั้งชื่อไฟล์ตามโครงสร้าง template เพื่อสะดวกต่อการตรวจ
- ส่งผ่าน commit/pull request หรือช่องทางที่ผู้สอนกำหนด
- ใช้ข้อความกระชับ ตรวจสอบย้อนกลับได้ และเชื่อมหลักฐานกับ requirement / test result เสมอ
