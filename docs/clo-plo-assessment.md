# CLO / PLO / การประเมินผล

## PLO ที่รายวิชาขับเคลื่อน

| PLO | บทบาทของ ENGSE601 |
|---|---|
| PLO1 | เสริมหลักการและทฤษฎีสำคัญของวิศวกรรมซอฟต์แวร์ โดยเฉพาะ V&V และจริยธรรมในการใช้ข้อมูล/AI |
| PLO2 | วิเคราะห์ข้อกำหนด ออกแบบการทดสอบ และประเมินความสอดคล้องของระบบกับข้อกำหนด |
| PLO3 | ประยุกต์เทคนิค V&V ในบริบทระบบจริง ใช้เครื่องมือ และจัดทำหลักฐานเชิงวิชาชีพ |
| PLO5 | ทำงานเป็นทีม สื่อสารผลการทดสอบ รับผิดชอบบทบาท และพัฒนาตนเองอย่างต่อเนื่อง |

## Mapping CLO → หลักฐานหลัก

| CLO | หลักฐาน |
|---|---|
| CLO1 | Concept quiz, process map, midterm/final |
| CLO2 | Requirement Review Sheet, RTM, peer review |
| CLO3 | Test case suite, integration/UAT scenarios, test data, NFR outline |
| CLO4 | Test Plan, risk list, estimation, monitoring approach |
| CLO5 | Defect log, metric snapshot, test summary report |
| CLO6 | AI Use Declaration, peer review evidence, individual reflection |
